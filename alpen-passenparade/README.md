# Alpen Passenparade – reisboek & kaart

Interactieve reisgids voor de 11-daagse motorreis *Alpen Passenparade* (MTR Motorreizen), met start en finish in Bovensmilde.

- Klikbare dagen met kilometers, rijtijden, passen en foto's
- Satellietkaart (Sentinel-2) met de routes per dag
- 3D-weergave (three.js) van dag 2 t/m 10, met passen als zuilen en een camera die de route vliegt
- Reisboek met praktische info

## Online zetten met GitHub Pages
1. Ga in deze repository naar **Settings → Pages**.
2. Kies bij *Source* **Deploy from a branch**, branch `main`, map `/ (root)`, en klik **Save**.
3. Na een minuut staat de site op `https://<jouw-gebruikersnaam>.github.io/<repo-naam>/`.

## Bronnen
